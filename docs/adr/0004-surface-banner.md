# The session banner names the surface from the base URL, not from a flag

Every command prints the account and whether it is talking to LIVE Hostaway or a SANDBOX stand-in. The judgement is made from the base URL alone: only Hostaway's own host is LIVE. A flag could be set wrongly in either direction; reading "LIVE" over a fake server is the same mistake as reading "SANDBOX" over the real one, and the URL is the one fact that cannot be mislabelled.
